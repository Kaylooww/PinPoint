## How to run
```sh
mineru server start          # basic tier, managed; check: mineru server status --json
cd backend && source .venv/bin/activate && uvicorn app.main:app --reload --port 8000
cd frontend && npm run dev   # http://localhost:5173
```
Reset both demo workspaces (servers running): `cd backend && .venv/bin/python scripts/reset_demo.py`
Warm the answer cache (after the final backend start): `cd backend && .venv/bin/python scripts/warm_cache.py`

Tests (throwaway data dir): `cd backend && .venv/bin/python tests/test_core_fixture.py`, `tests/test_folders.py`, and `tests/test_excerpts.py` (no network), and `tests/test_documents.py` (raw/text endpoints refuse unknown and path-like ids), and `tests/test_context.py` and `tests/test_suggestions.py` (`--offline` skips their live parts), `tests/test_picker.py` (folder picker contract, dialog faked), `tests/test_tiers.py` (tier choice and flash→basic fallback), `tests/test_structured.py` (answer item kinds and per-item citation rules), `tests/test_breadcrumbs.py` (heading paths, resets, TOC pages), `tests/test_encrypted.py` (decrypted copy, password message, 20-page chunks, skip note, HTML tables), `tests/test_hybrid.py` (embedding fallbacks offline, zero outbound with LLM_PROVIDER=none, plus a live "Who is the renter?" check; `--offline` skips the live part). Add `LLM_PROVIDER=none` to test extractive mode.

## Known issues
- "Who signed the engagement letter for the bakery?" (not a demo question) returns not_found: the generated letter's two-column signature block splits names from titles. Don't use it in the demo.
- Ollama must be running (open the app or `ollama serve`); otherwise /api/health shows llm and embeddings not ok and answers fall back to extractive mode with BM25. After ~5 idle minutes Ollama unloads the models: the next ask pays the ~6 s load.
- gemma4:e2b misses 3 of the 11 demo questions that Haiku answered (see In progress). Use the questions it answers in the demo, or try a larger local model.
- uvicorn --reload re-seeds an empty Reyes & Partners on restart; reset_demo.py now tolerates that race (it happened once when a script edit triggered a reload mid-reset).
- A git checkout/pull in this folder while `npm run dev` runs can stall Vite's Tailwind step (pages lose all styling). Fix: restart `npm run dev`. Happened once at 13:54.
- Bare follow-ups with only a very common word ("Who is the renter?") can retrieve the wrong passages and return Not found.
- Figma MCP (claude.ai connector) disconnected at 13:35; new screens reuse existing components until it is re-authenticated.
- Browser walkthrough driver (CDP, no deps) lives in the agent scratchpad, not the repo.
- Start `mineru server` from a stable directory: its managed parse service writes `.mineru-service.lock` and `blobs/` into the current directory (both git-ignored).
- The organizers' server (gone) rejected `temperature` and non-strict `response_format`; llm.py still sends neither to a non-local server.
- MinerU's own status shows a `remote` parse server (https://mineru.net/api) being health-probed. PinPoint never parses remotely, but that probe is MinerU's outbound traffic, not ours.
- `backend/samples/` holds real documents and is git-ignored (the repo is public).
